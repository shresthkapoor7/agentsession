<h1><img src="frontend/app/icon.svg" width="32" height="32" alt="agentsession logo" /> agentsession</h1>

A browser viewer for Codex and Claude session rollout files.

Choose a local `rollout-*.jsonl` file and view the transcript, tool calls, and session usage. Parsing happens in your browser. Nothing is uploaded.
