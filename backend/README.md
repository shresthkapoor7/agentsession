# agentsession API

FastAPI control plane for publishing and retrieving client-encrypted transcript
blobs. Supabase provides private object storage and Postgres; plaintext transcript
content and browser encryption keys never reach this service.

## Local setup

1. Copy `.env.example` to `.env` (a local `.env` with the project URL already
   exists in this checkout).
2. Add the Supabase service-role key, a random capability hash pepper, and a
   random internal cleanup token. Never expose these values to the frontend.
3. From this directory, run `uv sync` and then `uv run uvicorn app.main:app --reload`.

Generate the two application secrets with `openssl rand -hex 32`. Railway should
receive the same settings as environment variables and use `/health` for health
checks.

The Supabase bucket is private. Browser uploads use a one-object signed upload
URL generated by this API. Supabase currently fixes signed upload URL validity at
two hours; the API independently expires publish intents after ten minutes.
